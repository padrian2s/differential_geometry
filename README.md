# Differential Geometry

Interactive differential geometry learning platform with 3D visualizations.

## Overview

A web application built with Vite that provides an interactive learning experience for differential geometry. Features 3D visualizations of geometric concepts, structured lessons, and interactive exercises.

## Contents

- `src/` -- Source files
- `public/` -- Static assets
- `dist/` -- Built output
- `index.html` -- Entry point
- `vite.config.js` -- Build configuration

## Getting Started

```bash
npm install
npm run dev
```

Or use `bash run.sh` to launch the development server.
